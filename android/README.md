# Tw Store Android

Aplicativo Android nativo da Tw Store.

- Application ID: `com.twstore.mobile`
- Servidor padrão: `https://tw-store-application.up.railway.app`
- Código Android: `android/app/src/main/`
- Firebase: adicione `android/app/google-services.json` quando o projeto Firebase estiver criado.

O aplicativo compila sem `google-services.json`, mas as notificações FCM ficam desativadas até esse arquivo ser incluído.
