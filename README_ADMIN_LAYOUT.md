# Tw Store — Painel Admin com navegação inferior

Atualização 2.5.0.

## Navegação administrativa

O painel do administrador passa a usar cinco áreas fixas na barra inferior:

- **Início** — dashboard com total de pedidos, catálogo ativo, tickets abertos, uso no mês e suporte recente.
- **Catálogo** — mantém categorias, cadastro/edição de produtos SMM e VPN e preços.
- **Relatórios** — abre o relatório semanal/mensal e Top 3 de usuários.
- **Suporte** — concentra os tickets enviados pelos clientes.
- **Ajustes** — WhatsApp, atalho de suporte, relatório e saída da administração.

O menu do usuário comum permanece Início / Pedido / Histórico / Carteira / Ajustes.

## Arquivos desta atualização

Substitua/adiciona os arquivos mantendo as pastas `src/` e `public/`. O Railway pode redeployar normalmente após a atualização da branch usada em produção.
